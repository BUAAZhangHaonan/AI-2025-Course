# mIoU 指标详解

## 什么是 mIoU？

**mIoU** = **mean Intersection over Union**（平均交并比）

这是语义分割任务中最重要的评估指标之一。

## IoU 的定义

对于单个类别：

```
IoU = (预测正确的像素数) / (预测+真实标签的并集像素数)
    = TP / (TP + FP + FN)
    = Intersection / Union
```

其中：
- **TP** (True Positive): 正确预测为该类的像素
- **FP** (False Positive): 错误预测为该类的像素
- **FN** (False Negative): 遗漏的该类像素

## 直观理解

想象两个圆圈（预测和真实标签）：

```
    预测         真实标签
     ●●●         ●●●
    ●●●●●       ●●●●●
   ●●●●●●●     ●●●●●●●
    ●●●●●       ●●●●●
     ●●●         ●●●

重叠部分 = Intersection（交集）
全部部分 = Union（并集）

IoU = 交集 / 并集
```

## mIoU 的计算

对于DeepCrack（2类：背景和裂缝）：

```
IoU_background = Intersection_bg / Union_bg
IoU_crack = Intersection_crack / Union_crack

mIoU = (IoU_background + IoU_crack) / 2
```

## 评分标准

| mIoU范围 | 性能评价 |
|----------|---------|
| 90-100% | 优秀 |
| 80-90% | 良好 |
| 70-80% | 一般 |
| 60-70% | 较差 |
| <60% | 差 |

## 您的训练结果分析

### 观察到的mIoU变化

```
迭代 200:  mIoU: 76.02%  ← 最佳
迭代 400:  mIoU: 76.52%  ← 保存的best模型
迭代 600:  mIoU: 74.61%
迭代 800:  mIoU: 72.93%
...
迭代 5000: mIoU: 73.40%
```

### 关键发现

1. **最佳性能在第400轮**
   - mIoU达到76.52%
   - 这是一个不错的成绩（良好水平）

2. **明显的过拟合**
   - 400轮后mIoU开始波动下降
   - 从76.52%下降到71-75%之间波动

3. **为什么400轮的模型效果好？**
   - 模型刚好学到了裂缝的特征
   - 还没有开始记忆训练集的噪声
   - 泛化能力最强

## 为什么5000轮效果差？

### 过拟合现象

```
训练集：准确率接近100%
测试集：效果变差

原因：
- 模型记住了训练样本的特殊性
- 对测试集的新样本泛化能力下降
- 学习到了噪声而非真实特征
```

### 验证数据波动

注意到后期mIoU在71-75%之间波动：
- 这说明模型不稳定
- 对训练集过度敏感
- 没有学到鲁棒的特征

## 改进建议

基于您的训练曲线，建议：

1. **减少训练轮次**
   - 从5000 → 1000轮
   - 最佳点在400轮左右

2. **增加验证频率**
   - 从每200轮 → 每10-20轮
   - 及时发现最佳点

3. **早停策略**
   - 如果mIoU连续N次不提升，停止训练
   - 避免过拟合

4. **其他优化**
   - 增加数据增强
   - 使用Dropout
   - 减小学习率
